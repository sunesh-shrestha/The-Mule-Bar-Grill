# The Mule Bar & Grill

A multi-page restaurant website for a pub-style bar and grill in Sussex, NB, with an interactive online ordering page.

**Live demo:** [[The Mule Bar Grill](https://sunesh-shrestha.github.io/The-Mule-Bar-Grill/)]


## What it does

- Shows the restaurant's story, menu, photo gallery, events calendar, location and contact info
- **Order page:** customers pick menu items and see a live subtotal, 13% HST, and total, plus a summary of their selections
- Fully linked navigation with a dropdown menu and a sitemap page

## Pages

| Page | Purpose |
|------|---------|
| Home | Landing page |
| About | Restaurant story |
| Menu List / Gallery / Calendar | Food, photos, events |
| Order | Interactive order builder |
| Location / Contact | Find and reach the restaurant |
| Sitemap | Overview of all pages |

## Built with

- HTML5
- CSS3 (custom styling, responsive layout)
- Vanilla JavaScript (order calculations and DOM updates)

## How to run locally

1. Clone the repo: `git clone https://github.com/sunesh-shrestha/The-Mule-Bar-Grill.git`
2. Open `index.html` in your browser. No install needed.
